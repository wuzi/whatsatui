# Fictional demo images

These images were generated with the built-in image generation tool for the offline `--demo` scene. No personal contact photos, account data, or screenshot references were supplied. The names and conversations are fictional. The images are bundled in the binary; demo mode never fetches them from a website.

Portraits and the trail group photo are 256-pixel JPEG exports; the café photo is a 768-pixel JPEG export. Originals were downscaled and encoded with ImageMagick, with metadata removed. `cafe.jpg` is shared by the inline photo and coffee-related group avatars; `trail.jpg` is shared by outdoor groups. The original generated images were retained outside the repository.
